# НА МЕСТЕ — развозка детей

Веб-приложение, которое ставится на iPhone с экрана «Домой», как LeStart.
Три режима в одном приложении:

| Кто | Адрес | Что делает |
|---|---|---|
| Родитель | `/app` | где сейчас ребёнок, неделя, подтверждение и отмена, уведомления |
| Водитель | `/driver` | смена по точкам: «Еду сюда», посадка и передача свайпом, координаты |
| Диспетчер | `/admin` (компьютер) | день по машинам, карта, семьи, коды входа, журнал уведомлений |

Всё бесплатно: сервер свой, карты открытые (OpenStreetMap), уведомления — Web Push, вход — код приглашения.
Как устроено и почему — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Запуск на компьютере

```bash
npm install
npm run seed      # демо-семья Маша и Лёва, машина, неделя поездок; печатает коды входа
npm run dev       # сервер :3000 и приложение http://localhost:5173
```

Откройте `http://localhost:5173/login` и введите код из вывода `npm run seed`:
у мамы — экран родителя, у Дмитрия — водитель и диспетчерская.

## Проверки

```bash
npm test          # правила поездок, повторы, время, тексты уведомлений
npm run typecheck # типы по всему проекту
```

## Выкладка на домашний сервер

```bash
bash scripts/deploy-home.sh
```

Копирует код на `home-lan`, запускает сервис `na-meste` и открывает HTTPS через Tailscale:
`https://mitriy.tailcb9627.ts.net`. Подробности и следующий шаг (доступ родителям без Tailscale) —
в разделе «Хостинг» архитектуры.

## Папки

```
shared/   правила, общие для сервера и приложения: состояния поездки, повторы, время, тексты
server/   API (Fastify), база (SQLite через Drizzle), модули: вход, поездки, планировщик,
          трекинг и геозоны, уведомления, фоновые задачи
web/      приложение (React): родитель, водитель, диспетчер; service worker для уведомлений
scripts/  запуск для разработки и выкладка на сервер
data/     база, ключи уведомлений и резервные копии (в git не попадает)
```
