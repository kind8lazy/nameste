# Архитектура НА МЕСТЕ (этап 1, бесплатный запуск)

Документ фиксирует решения, принятые 28.09.2026. Исходный план с исследованием переписок и
интеграцией LeStart: https://claude.ai/artifact/9A4KgRQAWhuUUoagLpLCzN

## Главное решение: ноль платежей до первых клиентов

| Задача | Платный вариант | Что используем | Чем платим |
|---|---|---|---|
| Приложение на iPhone | App Store, $99/год, зарубежная карта | веб-приложение на экран «Домой» | нет живого статуса на экране блокировки (заменён уведомлением с одним тегом, которое обновляется) |
| Сервер и данные в РФ | VPS 800–1500 ₽/мес | домашний сервер Ubuntu (4 ядра, 8 ГБ) | зависимость от домашнего интернета и питания |
| HTTPS и адрес | домен 200–900 ₽/год | Tailscale (`*.ts.net`), бесплатный сертификат | на старте открывается только на устройствах с Tailscale; для родителей — Funnel или проброс порта + DuckDNS |
| Вход | SMS 3–6 ₽ за код | 8-значный код приглашения от диспетчера, 6-значный код для второго устройства | код передаётся мессенджером вручную |
| Уведомления | SMS | Web Push (VAPID), для iPhone iOS 16.4+ | на iPhone только после добавления на экран «Домой» |
| Карта | Яндекс, коммерческая лицензия от 195 000 ₽/год (бесплатная запрещает слежение за транспортом) | MapLibre + OpenFreeMap (данные OpenStreetMap) | нет пробок на карте |
| Время в пути | Яндекс Матрица расстояний | OSRM (открытый) + поправка на час пик ×1,4–1,7 | точность хуже в пробки |
| Поиск адреса | Яндекс Геокодер | Nominatim (OpenStreetMap), 1 запрос/с, кеш | медленнее, адреса иногда неточные — точку можно поправить вручную |
| Координаты водителя в фоне | нативное приложение | бесплатный Traccar Client (App Store) → наш `/api/osmand` | водителю надо поставить второе приложение |
| База | PostgreSQL на сервере | SQLite (файл) через Drizzle ORM | переезд на PostgreSQL — смена диалекта, логика не меняется |

Всё, что сейчас бесплатно, заменяется платным без переписывания: каждый внешний сервис спрятан
в одном модуле (`server/modules/geo.ts`, `notify.ts`, `auth.ts`).

## Схема

```
iPhone родителя ─┐                     ┌─ OSRM (время в пути)
iPhone водителя ─┤  HTTPS (Tailscale)  │─ Nominatim (адреса)
Traccar Client ──┼────────────────────►│  Сервер НА МЕСТЕ (Node, Fastify)
Компьютер ───────┘   REST + SSE        │   ├ вход и сессии
                                        │   ├ семьи, дети, места
                                        │   ├ расписание → поездки на 14 дней
                                        │   ├ планировщик рейса
                                        │   ├ поездки и журнал событий
                                        │   ├ трекинг, геозоны, ETA, задержки
                                        │   ├ уведомления (Web Push)
                                        │   └ фоновые задачи
                                        └─ SQLite (data/na-meste.db), резервные копии каждую ночь
                                           Web Push → серверы Apple/Google → телефоны
```

## Модель данных (server/db/schema.ts)

- **Семья → члены семьи** (мама-владелец, папа, бабушка) с уровнем уведомлений: всё / главное / только «передан».
- **Ребёнок**: имя, класс, кресло, заметки, кому можно передавать, связь с учеником LeStart.
- **Место**: адрес, координаты, «как пройти», радиус геозоны. Общие места (школа, секция) видны всем семьям.
- **Шаблон поездки**: ребёнок, откуда, куда, время, правило повтора (RRULE: по дням, через неделю, разово), цена.
- **Исключение**: отмена или другое время на одну дату — шаблон не трогаем.
- **Поездка**: один ребёнок, один отрезок, одна дата. Создаётся из шаблона на 14 дней вперёд.
- **Рейс → точки**: машина и водитель на день, упорядоченные точки забора и высадки.
- **Событие поездки**: журнал только на добавление (кто, что, когда, где).
- **Координаты**: хранятся 30 дней. **Подписки на уведомления**, **журнал уведомлений**, **сессии**, **коды входа**.

## Состояния поездки (shared/domain.ts)

```
в плане → подтверждена → водитель едет → у точки → в машине → передан
                ↓               ↓            ↓
             отменена        отменена     не вышел → (вышел позже) → в машине
```
Переходы проверяются в одном месте (`applyEvent`) и покрыты тестами. Недопустимое действие
возвращает понятный текст: «Нельзя „передать“, когда поездка в состоянии „передан“».

## Как проходит поездка

1. 19:00 накануне — «Завтра 3 поездки. Всё в силе?» (кнопка «Да» подтверждает весь день).
2. Водитель жмёт «Еду сюда» → семьи: «Дмитрий выехал, будет около 14:08».
3. Геозона 150 м (или кнопка «Я на месте») → «Дмитрий на месте».
4. Свайп «Посадил: Маша, Лёва» → одно сообщение семье: «Маша и Лёва в машине · 14:21».
5. На карте у родителя — золотая точка машины, обновление каждые 5–10 с.
6. Свайп «Передал: Маша → тренер» → «Маша на месте · 14:34. „Теннис“: передан — тренер».
7. Прогноз хуже плана на 5+ минут → «Задержка ~7 мин».
8. Не вышел → «Маша: не вышел. Позвоните водителю» + уведомление диспетчеру.

Уведомления одного забора идут с одним тегом, поэтому на экране блокировки видно одно
сообщение, которое обновляется, а не пачка.

## Хостинг

**Сейчас:** домашний сервер, сервис `systemd --user` `na-meste`, порт 3100 только на 127.0.0.1,
HTTPS через `tailscale serve` → `https://mitriy.tailcb9627.ts.net`. Открывается на устройствах
в вашей сети Tailscale — этого достаточно для проверки на себе и водителе.

**Для первых родителей (выбрать одно, оба бесплатны):**
- Tailscale Funnel — тот же адрес становится публичным. Включается одной галочкой в админке
  Tailscale. Трафик идёт через узлы Tailscale за рубежом (зашифрован, данные хранятся у вас).
- Проброс портов 80/443 на роутере + бесплатное имя DuckDNS + сертификат Let's Encrypt.
  Трафик идёт напрямую, но нужен доступ к роутеру.

**Когда появятся деньги:** VPS в России и свой домен — переезд командой `deploy-home.sh`
с другим `DEPLOY_HOST`.

## Безопасность

- Сессия — httpOnly-cookie на 180 дней, в базе хранится только хеш.
- Коды входа: 8 цифр на 7 дней (до 5 входов), 6 цифр на 10 минут; 10 попыток за 15 минут с адреса.
- Родитель видит только поездки своей семьи; координаты машины — только пока его ребёнок в пути.
- Водитель видит детей только своего рейса.
- Координаты хранятся 30 дней, база копируется каждую ночь (14 последних копий).
