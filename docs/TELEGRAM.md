# Телеграм: мини-приложение и бот — архитектура

Дата: 20.10.2026. Статус: предложение, не начато.

## Зачем
- **Уведомления, которые точно дойдут.** На iPhone веб-уведомления работают только после установки на экран «Домой» — многие родители этого не сделают. Сообщение от бота приходит всем, у кого есть Телеграм.
- **Вход без Яндекса и кодов.** Телеграм сам подтверждает, кто открыл приложение.
- **Привычно.** Родители и так переписываются в Телеграме; диспетчеру проще отвечать там же.

## Главное ограничение (проверено 20.10.2026)
Боевой сервер в России **не достаёт до api.telegram.org** (соединение не устанавливается). Значит, бот не может работать прямо на нём без обходного пути. Варианты ниже, в разделе «Связь с Телеграмом».

## Принцип
Один источник правды — наш сервер `na-meste-spb.ru` (база в России). Телеграм — только ещё одно «окно» и ещё один канал уведомлений, как почта или push. Никакой логики и данных в боте не живёт.

```
Родитель/водитель в Телеграме
   │  1) открывает мини-приложение (кнопка в боте)
   ▼
https://na-meste-spb.ru/tg   ← то же веб-приложение React, режим «внутри Телеграма»
   │  2) присылает initData (подпись Телеграма)
   ▼
Наш сервер (Россия): проверяет подпись → находит человека по telegram_id → сессия
   │  3) события поездок и чата
   ▼
Канал «telegram» в модуле уведомлений → шлюз → Bot API → сообщение в Телеграм
```

## Части

### 1. Мини-приложение (Telegram Mini App)
- **То же приложение**, что на сайте: адрес `https://na-meste-spb.ru/tg`. Переписывать экраны не нужно.
- Подключаем `telegram-web-app.js`; берём цвета темы, кнопку «Назад», главную кнопку Телеграма вместо своих там, где это удобнее.
- Простой режим (LITE_MODE) действует так же: видно только детей, маршруты, календарь, имена, чат.
- Роли: родитель (сегодня, неделя, чат, места), водитель (смена — удобно в Телеграме на телефоне), диспетчер — по-прежнему на компьютере в браузере.

### 2. Вход через Телеграм
- При открытии мини-приложение передаёт `initData`; сервер проверяет подпись по токену бота (HMAC-SHA256, срок не старше 1 часа). Подделать нельзя.
- **Привязка к человеку в базе** (один раз):
  1. Бот просит «Поделиться номером» (кнопка Телеграма). Телеграм отдаёт подтверждённый номер владельца аккаунта.
  2. Если номер совпадает с родителем, которого завёл диспетчер, — привязываем `telegram_id` к нему.
  3. Если не совпал — человек попадает в «ждут семью» у диспетчера, как сейчас при входе через Яндекс.
  4. Запасной путь — код диспетчера (как сейчас).
- Сотрудникам (диспетчер, водитель) вход через Телеграм — только если номер совпал с их записью, без автосоздания.
- Новое поле в базе: `users.telegram_id` (уникальное), таблица `telegram_links` не нужна.

### 3. Бот
Бот — тонкий: кнопки и уведомления.
- `/start` — приветствие, кнопка «Открыть приложение», кнопка «Поделиться номером» для привязки.
- **Уведомления** (новый канал рядом с push и почтой): «водитель выехал», «в машине», «на месте · Принял: бабушка», напоминание на завтра, новое сообщение в чате. В каждом — кнопка «Открыть».
- **Ответы в чат:** родитель отвечает боту обычным сообщением → оно попадает в чат семьи в приложении; ответ диспетчера приходит родителю в бот. Диспетчер работает в приложении, как сейчас.
- **Кнопки в уведомлениях:** «Подтвердить завтра», «Отменить (заболел)» — без захода в приложение (с проверкой прав, как в приложении).
- Настройки: какие уведомления получать (всё / главное / только «передан»), выключить.
- Минимум данных в сообщениях: имя ребёнка и место, без адресов и телефонов.

### 4. Связь с Телеграмом (из-за блокировки на сервере)
| Вариант | Как | Плюсы | Минусы |
|---|---|---|---|
| **А. Шлюз за рубежом** (рекомендую) | Маленький сервис на зарубежном сервере (~300–500 ₽/мес) или в бесплатном облаке. Принимает вебхуки от Телеграма и пересылает нам; наши команды «отправь сообщение» передаёт в Bot API. Связь шлюз ↔ наш сервер — HTTPS с общим секретом. | Надёжно, не зависит от прокси | Ещё один сервер; данные идут через зарубежный узел (как и в самом Телеграме) |
| Б. Прокси на нашем сервере | Исходящие запросы к Bot API через прокси (как на домашнем сервере, v2raya) | Без нового сервера | Прокси падают и блокируются — уведомления перестанут уходить |
| В. Бот на домашнем сервере | Там прокси уже есть; бот ходит к нам по HTTPS | Бесплатно сейчас | Дом — свет, интернет, перезагрузки; для боевого сервиса ненадёжно |

Модуль уведомлений шлёт в Телеграм через **очередь с повторами**: если шлюз недоступен, сообщения дойдут позже, а приложение и почта продолжат работать.

## Закон о персональных данных
- Телеграм — зарубежный сервис: имена детей и места в сообщениях бота — **трансграничная передача** персональных данных. Нужно: согласие родителя (отдельной галочкой «получать уведомления в Телеграме»), уведомление Роскомнадзора о трансграничной передаче, минимум данных в сообщениях.
- База остаётся в России, в Телеграм уходят только тексты уведомлений и чата.
- Проверить у юриста актуальные ограничения на использование иностранных мессенджеров для связи с клиентами.
- Альтернатива на будущее: тот же подход для мессенджера MAX (российский), если родители там.

## План работ
1. **Неделя 1:** бот (создаёте в @BotFather, токен — только в secrets на шлюзе), шлюз, привязка по номеру, уведомления о поездках и чате. Уже даёт главную пользу.
2. **Неделя 2:** мини-приложение (вход по initData, адаптация экранов под Телеграм), кнопки «подтвердить / отменить» в уведомлениях, ответы в чат через бота.
3. **Потом:** смена водителя в мини-приложении, настройки уведомлений, MAX.
