# Телеграм-бот для заявок новых семей

Родитель пишет боту → бот задаёт вопросы по одному (имя, телефон, дети, откуда, куда, когда, комментарий) →
показывает заявку на проверку → «Отправить». Заявка сразу приходит диспетчеру в Телеграм и попадает во
«Входящие» приложения (карточка «Новая семья» с кнопками «Позвонить», «Написать», «Связались», «Отказ»).

Код: `bot/dialog.ts` (разговор, проверен тестами), `bot/telegram-bot.ts` (связь с Телеграмом),
`server/modules/leads.ts` и `server/routes/leads.ts` (приём заявок на сайте).

## Где запускать
Боевой сервер в России **не достаёт до api.telegram.org**, поэтому бот — отдельная программа. Запускайте там,
где Телеграм открывается: зарубежный сервер (300–500 ₽/мес), домашний сервер с прокси или Mac — для проверки.
Вебхук и домен не нужны: бот сам спрашивает Телеграм о новых сообщениях.

Если сайт недоступен, заявка не теряется: лежит в очереди (`data/bot/queue.json`) и досылается раз в минуту.
Диспетчеру в Телеграм она приходит сразу в любом случае.

## Настройка — 4 шага
1. **Создать бота.** В Телеграме откройте @BotFather → `/newbot` → имя «НА МЕСТЕ» и адрес вроде `na_meste_spb_bot`.
   BotFather пришлёт токен.
2. **Секрет для сайта.** Придумайте длинную случайную строку (например, `openssl rand -hex 24`).
   На сервере добавьте её в `/opt/na-meste/secrets.env` строкой `LEADS_SECRET=…` и перезапустите приложение
   (или выкатите — `bash scripts/deploy-prod.sh` переносит secrets.env).
3. **Настройки бота.** Скопируйте `bot.env.example` в `bot.env` и впишите токен, `LEADS_SECRET` и `APP_URL`.
4. **Запуск.** `npm install`, затем `npm run bot`. Напишите боту `/id` — он ответит номером вашего чата.
   Впишите номер в `TELEGRAM_ADMIN_CHAT_IDS` (несколько — через запятую) и перезапустите бота.

Чтобы бот работал постоянно на сервере — systemd-служба с `npm run bot` в папке проекта (как у приложения).

## Данные
В заявке — имя и телефон родителя, имена и классы детей, адреса своими словами. Они проходят через Телеграм;
перед «Отправить» бот предупреждает об этом. В базе на сайте хранятся в таблице `leads`.
Бот принимает не больше 5 заявок в сутки с одного аккаунта и отвечает только в личной переписке.
